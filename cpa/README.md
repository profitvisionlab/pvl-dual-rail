> 專案啟動日：2026-08-27（民國 115 年）

## 現況

- 正在補修應考資格學分：會計研究發展基金會「中級會計學學分班第 45 期」（視訊、週一夜間班，2025-10 開課），成績與學分證明申請中。

- 備考教材與歷屆試題已集中在 Google Drive「CPA 會計師」資料夾。

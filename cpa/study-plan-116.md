# 116 年會計師考試讀書計畫（草案）

> 預設目標：116 年 8 月考試（2027-08），自 2026-09 起約 11 個月備考期。
> 原則：以歷屆試題為導向（考畢題答 110–114 已齊），教材先讀有課程支撐的科目。

## 階段規劃

### Phase 0 — 定錨（2026-09 上半）
- 取得中會學分班第 45 期成績與學分證明，確認應考資格是否齊備。
- 對照考選部 116 年簡章（約 2027 年春公告，先以 115 年版推估）確認科目與保留規定。
- 決定應考科目組合（7 科全上 vs. 分年：第一年主攻中會＋稅法＋審計）。

### Phase 1 — 正課期（2026-09 ～ 2026-12）
- **中會**：跟學分班進度走，每章配 110–114 歷屆題演練。
- **稅務法規**：教材最完整（正課／講義／階段複習），每週固定 2 個晚上；所得稅法→營業稅法→遺贈稅→土地稅→稽徵法的順序。
- 每月月底：做一回歷屆申論題限時演練。

### Phase 2 — 第二輪科目（2027-01 ～ 2027-04）
- **審計學**：以 115CPA 審計學講義為主軸，搭配公報架構整理。
- **公證商三法**：只有考古題，1 月前補一套教材或函授；以法條記憶＋考古題反覆為主。
- 中會、稅法轉入維持模式（每週各一回歷屆題）。

### Phase 3 — 總複習期（2027-05 ～ 2027-07）
- 全科目切換到「總複習＋歷屆題限時全真演練」：每週末一科完整模考（申論＋測驗題）。
- 錯題本收斂：只複習錯過的題與常考法條。
- 國文作文：每兩週一篇限時練筆，用 CPA_國文作文 資料夾範文對照。

### Phase 4 — 考前衝刺（2027-07 下旬 ～ 考試日）
- 停止新教材，只做：錯題本、法條速記表、近三年（112–114）考題重刷。
- 調整作息至考試時段節奏。

## 每週節奏（Phase 1 範本）

| 時段 | 內容 |
|------|------|
| 週一晚 | 中會學分班（課程） |
| 週二・週四晚 | 稅務法規正課進度 |
| 週三晚 | 中會複習＋習題 |
| 週五晚 | 彈性補進度／休息 |
| 週六 | 3 小時主科塊狀學習＋1 回歷屆測驗題 |
| 週日 | 週複習＋錯題整理（90 分鐘） |

## 歷屆題使用法

1. 第一遍（正課期）：讀完一章 → 做該章對應考點的歷屆題，開書也沒關係。
2. 第二遍（總複習期）：整回限時演練，測驗題 25 題掐 50 分鐘，申論題逐題手寫。
3. 對答案一律以官方標準答案（ANS 檔）為準；114 稅法第 20 題有更正答案（MOD 檔，A/B 均給分）這類更正要記得看。

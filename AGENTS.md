## Ground rules (pvl-dual-rail)

- **Zero runtime dependencies.** A PR that adds one needs a compelling reason.
- **The policy gate is the product.** `src/policy.mjs` must never be weakened:
  internal data (`internalContext: true` or `sensitivity: 'internal'`) never
  reaches the FinOps rail, and an explicit `rail: 'finops'` is not an opt-out.
- The smoke suite runs fully offline (`ENTERPRISE_ADAPTER=mock`, no keys needed);
  new policy behavior ships with a smoke check in the same commit.
- Node ≥ 20, ESM only (`.mjs`). No build step.
